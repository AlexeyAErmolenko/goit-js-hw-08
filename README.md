Завдання — Галерея зображень <br>
Створи галерею з можливістю кліку по її елементах і перегляду повнорозмірного зображення в модальному вікні. Подивись демовідео роботи галереї. <br>
Створення галереї — це комплексна задача, яку краще розбити на декілька простіших підзадач, виконуючи кожну з яких, ти будеш наближатися до кінцевої мети. Цей процес називається декомпозиція задачі. <br>
 <br>

3 - Розмітка елементів галереї <br>
У тебе є контейнер, в який можна додати елементи галереї, і дані, за якими їх можна створити. Саме час наповнювати галерею розміткою. <br>
Використовуй масив об’єктів images і цей HTML шаблон елемента галереї та створи в JavaScript коді розмітку елементів, після чого додай усю розмітку всередину ul.gallery. Не додавай інші HTML теги, крім тих, що містяться в цьому шаблоні. <br>
 <br>
<li class="gallery-item">
  <a class="gallery-link" href="large-image.jpg">
    <img
      class="gallery-image"
      src="small-image.jpg"
      data-source="large-image.jpg"
      alt="Image description"
    />
  </a>
</li>
 <br>
    В атрибуті src тега <img> вказуємо посилання на маленьку версію зображення. <br>
    Для атрибута alt використовуємо опис зображення. <br>
    Посилання на велике зображення повинно зберігатися в data-атрибуті source на елементі <img>, і вказуватися в href посилання. <br>
    Зверни увагу на те, що зображення огорнуте посиланням, у якого атрибут href вказує на шлях до файлу з зображенням. Отже клік по ньому може викликати завантаження зображення на комп’ютер користувача. Заборони цю поведінку за замовчуванням. <br>
 <br>
4 - Стилі <br>
Додай стилізацію галереї згідно макету. <br>
 <br>
5 - Делегування <br>
 <br>
Саме час додати функціонал прослуховування кліка по елементах галереї та отримання посилання на велике зображення при кліку. Для цього використовуй прийом делегування на ul.gallery. Поки що при кліку на елемент галереї виводь у консоль посилання на велике зображення, що зберігається як значення атрибуту data-source елемента img. <br>
 <br>
6 - Підключення бібліотеки <br>
Бібліотека basicLightbox представляє повністю функціональне модальне вікно, яке відмінно підходить під нашу задачу. Використовуй CDN сервіс jsdelivr і додай в HTML файл посилання на мініфіковані (.min) JS та CSS файли бібліотеки. <br>
 <br>
7 - Модальне вікно <br>
Доповни свій код так, щоб при кліку по елементу галереї відкривалось модальне вікно підключеної бібліотеки. Для того щоб дізнатися, як ініціалізувати модальне вікно у своєму коді і як його використовувати, ознайомся з документацією і прикладами. <br>
 <br>
8 - Велике зображення <br>
Використовуй свій код отримання посилання на велике зображення із атрибуту data-source, щоб замінити значення атрибута src елемента <img> в модальному вікні перед відкриттям. Використовуй готову розмітку модального вікна із зображенням із прикладів бібліотеки basicLightbox. <br>
 <br>
